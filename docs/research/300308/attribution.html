中际旭创 300308.SZ · 股价事后归因

一、三层恒等式：市值 = 远期共识净利 × PE_NTM 每层都恒等，残差为 0

对数空间分解，同一层内各项相加精确等于上一层的变动，没有残差项可以藏东西：

L0 Δln 市值 = Δln 股本 + Δln 股价 ── 只用来拆发行/转增，不影响下层恒等
L1 Δln 市值 = Δln E_NTM + Δln PE_NTM ── 盈利 vs 估值，第一刀
L2b Δln E_NTM = 日历滚动 + 共识真实修正 ── 冻结预测集法分离
L2a Δln PE_NTM = 大盘 + 行业相对 + 个股相对 ── 乘法链，三项相乘 ≡ PE_NTM
桥 前瞻溢价 ≡ Δln E_TTM − Δln E_NTM ── 不是因子，是两个盈利口径的差

为什么“前瞻溢价”单独拎出来：它恒等于 Δln(PE_NTM/PE_TTM)，也就是两个盈利口径之差，一分钱估值因素都不含。 把它跟大盘/行业/个股平列，就会把“共识跑得比报表快”误读成“情绪因子”。下面主表只用 L2a+L2b 五项，前瞻溢价与 TTM 口径放在第四节做交叉验证。

怎么读这两列数字：「区间涨幅」是简单收益 e^Δln − 1；后面五列是对数贡献，单位是 pp， 段内相加等于该段的 Δln（写在涨幅下面的小字），不等于涨幅。大行情时两者差得很远—— 例：2026-03-09→06-22 市值 5,844→15,416 亿（×2.64），Δln +97.0pp ⇔ 涨幅 +163.8%。 之所以用 Δln：只有对数空间里乘法链才能拆成可相加的加法链（残差恒为 0）。

四、口径交叉验证 两套恒等式 + 一扇桥

主表用的是 NTM/NTM 同口径（分子分母都是远期共识，不受报表确认节奏干扰）。 把分母换成 TTM 也能得到一套完全恒等的四项分解——两套并列，差的就是“共识 vs 报表”的节奏：

NTM 口径 Δln 市值 = (日历滚动 + 共识修正) + 大盘 + 行业(NTM) + 个股(NTM)
TTM 口径 Δln 市值 = Δln E_TTM + 大盘 + 行业(TTM) + 个股(TTM)
两者差 前瞻溢价 = Δln E_TTM − Δln E_NTM（纯盈利侧，不含任何估值因素）
